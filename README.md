# Sunil Store, public files

Build output only, never source. Everything here is published by the private repository's
**Publish site** workflow, which overwrites it: change things there, not here.

- **GitHub Pages:** the policy pages and the app download page at the root, and the store's admin
  panel under `admin/`.
- **Releases:** the Android app's APK files, one release per version.
- **Actions → Keep alive:** checks the store's server every 10 minutes in store hours.
